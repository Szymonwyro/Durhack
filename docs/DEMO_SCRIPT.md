# 60-second demo

1. **Command map:** one person walking, tracked by all cameras.
2. Hand the judge the **viewer phone**, facing a cardboard wall.
3. Person walks **behind the wall** → cyan ghost "via CAM 2" on the phone.
4. Person enters the **planned blind spot** → dashed outline, the cone grows, "predicted".
5. Person **re-emerges** where the cone pointed → snaps to solid, "reacquired".
6. Optional voice: *"contact, behind wall, 4 metres"*. Person waves → skeleton waves through the wall.
